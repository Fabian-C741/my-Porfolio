PORTFOLIO FABIÁN CÁCERES
========================

1. Abrí index.html en el navegador.
2. Cambiá TU_EMAIL@ejemplo.com por tu email.
3. Agregá tu LinkedIn.
4. Colocá tu CV como CV-Fabian-Caceres.pdf en esta misma carpeta.
5. Reemplazá los títulos de las certificaciones por sus nombres exactos.
6. Si querés publicar gratis: GitHub Pages, Netlify o Cloudflare Pages.

El diseño no necesita frameworks ni dependencias JS externas.
